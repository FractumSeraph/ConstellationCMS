About the site

Website

The ordinary web version of the site, for any browser.

Gemini (optional)

Gemini is a small, text-only cousin of the web, read with apps such as Lagrange. Your own server can serve the same posts there; GitHub Pages can't.

Gopher (optional)

Gopher is a menu-based text system from before the web, still loved by some readers. Your own server can serve the site there too.

Reader features

A post can override the table of contents with toc: true or toc: false, and becomes featured with featured: true (both on the editor's Details tab). Galleries: put images between ::: gallery and ::: lines.

Share links under posts (plain links, no tracking scripts) {% for n, label in share_networks %}{% endfor %}
{% set cm = doc.get('comments', {}) %}

Comments (web, under posts)

Set up the repository at giscus.app and copy the values it shows.

Disqus shows ads and tracks readers on its free plan.

Toot about a post, then put the toot's address in the post's Mastodon toot field (Details tab). Replies to it show under the post; Gemini and Gopher get a link to them.

A single post can turn comments off with comments: false.

Plugins

Plugins add features to the site while it is built. They are Python files in the plugins folder inside your sites folder (or installed Python packages). They run on this computer when the site is built, so only turn on plugins you trust. How to write one.
