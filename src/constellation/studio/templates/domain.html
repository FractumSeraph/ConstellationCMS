Domain

Your site's addresses are set on the Settings page. For people to reach them, your domain needs these DNS records. You add them where you bought the domain (Namecheap, Porkbun, GoDaddy, Cloudflare and so on), usually under DNS, DNS records or Advanced DNS.

Tips

  • Name: for the domain itself (example.com) most registrars want @; for www.example.com type just www.
  • Delete any other A record for the same name, often a "parking" page added by the registrar.
  • On Cloudflare, set the cloud to grey (DNS only), so Gemini and the server's HTTPS work.
  • Changes usually show up within minutes, sometimes up to a few hours. This page checks again by itself.
