# ConstellationCMS

A static site manager for multiple web stacks: write once in Markdown, publish to the web, to
Gemini, and later to Gopher, from one local studio with one Publish button.

Status: **planning**. The design lives in [`docs/plan/`](docs/plan/README.md); nothing is
implemented yet. Start with [the overview and decision record](docs/plan/01-overview-and-decisions.md).
